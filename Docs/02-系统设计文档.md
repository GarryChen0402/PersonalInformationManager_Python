# 个人信息管理器 — 系统设计文档

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 模块化 | 每个功能模块独立，拥有自己的数据模型、业务逻辑和 GUI 面板 |
| 关注点分离 | 数据模型（Model）、业务逻辑（Service）、用户界面（View）三层分离 |
| 无外部依赖 | 仅使用 Python 标准库（tkinter、json、os、datetime、base64、shutil 等） |
| 面向接口编程 | 每个模块定义统一的接口契约，便于替换和扩展 |
| 数据与逻辑分离 | 数据持久化层独立，业务逻辑不直接操作文件 |

### 4.1 Storage 层（`Core/Storage.py`）

```python
class JSONFileStorage:
    """JSON 文件存储基类，提供通用 CRUD 操作"""

    def __init__(self, file_path: str):
        """指定 JSON 文件路径，文件不存在时自动创建空数组"""

    def _load(self) -> list[dict]:
        """加载数据，返回字典列表。解析失败返回空列表"""

    def _save(self, data: list[dict]) -> None:
        """保存字典列表到文件（原子写入：先写临时文件再替换）"""

    def get_all(self) -> list[dict]:
        """获取所有记录"""

    def get_by_id(self, record_id: str) -> dict | None:
        """根据 ID 查询单条记录"""

    def query(self, **filters) -> list[dict]:
        """按字段条件筛选记录"""

    def add(self, record: dict) -> None:
        """新增记录（自动添加 created_at）"""

    def update(self, record_id: str, updates: dict) -> bool:
        """更新记录（自动更新 updated_at），返回是否成功"""

    def delete(self, record_id: str) -> bool:
        """删除记录，返回是否成功"""

    def count(self) -> int:
        """返回记录总数"""
```

```python
class App:
    """应用程序主窗口"""

    def __init__(self):
        self.root = tk.Tk()
        self.root.title("个人信息管理器 (PIM)")
        self.root.geometry("960x640")
        self.root.minsize(800, 500)

        # 状态栏
        self.status_bar = tk.Label(self.root, text="就绪", bd=1,
                                   relief=tk.SUNKEN, anchor=tk.W)

        # 左侧导航栏
        self.nav = NavFrame(self.root, on_select=self._switch_page)

        # 右侧内容区
        self.content = tk.Frame(self.root)
        self.content.pack(side=tk.RIGHT, fill=tk.BOTH, expand=True)

        self.pages: dict[str, tk.Frame] = {}
        self._init_pages()
        self._switch_page("profile")

    def _init_pages(self):
        self.pages["profile"] = ProfilePage(self.content, self.status_bar)
        self.pages["status"] = StatusPage(self.content, self.status_bar)
        self.pages["skill"] = SkillPage(self.content, self.status_bar)
        self.pages["knowledge"] = KnowledgePage(self.content, self.status_bar)
        self.pages["password"] = PasswordPage(self.content, self.status_bar)
        self.pages["backup"] = BackupPage(self.content, self.status_bar)
        self.pages["dashboard"] = DashboardPage(self.content, self.status_bar)

    def _switch_page(self, page_name: str):
        for page in self.pages.values():
            page.pack_forget()
        self.pages[page_name].pack(fill=tk.BOTH, expand=True)
        self.pages[page_name].refresh()

    def run(self):
        self.status_bar.pack(side=tk.BOTTOM, fill=tk.X)
        self.root.mainloop()
```

```python
class KnowledgePage(tk.Frame):
    """知识管理页面，内部包含 笔记 / 电子书 两个 Tab"""

    def __init__(self, parent, status_bar):
        super().__init__(parent)
        self.manager = KnowledgeManager()
        self.status_bar = status_bar

        # Tab 切换栏
        self.notebook = ttk.Notebook(self)
        self.note_tab = NoteTabView(self.notebook, self.manager, self.status_bar)
        self.ebook_tab = EbookTabView(self.notebook, self.manager, self.status_bar)
        self.notebook.add(self.note_tab, text="📝 文本笔记")
        self.notebook.add(self.ebook_tab, text="📖 PDF电子书")
        self.notebook.pack(fill=tk.BOTH, expand=True)

    def refresh(self):
        current_tab = self.notebook.select()
        tab_widget = self.notebook.nametowidget(current_tab)
        tab_widget.refresh()
```

### 6.2 PDF 文件存储

- 导入电子书时，将 PDF 文件复制到 `Data/books/` 目录
- 使用原始文件名或 `{uuid}.pdf` 命名以避免冲突
- knowledge.json 中存储相对路径 `books/xxx.pdf`
- 删除电子书时，可选择同时删除 PDF 源文件

### 6.3 原子写入

```python
def _save(self, data: list[dict]) -> None:
    tmp_path = self.file_path + ".tmp"
    with open(tmp_path, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
    os.replace(tmp_path, self.file_path)
```

### 6.4 备份格式

- 备份文件为单个 JSON，包含所有模块数据
- 文件名：`backup_YYYYMMDD_HHMMSS.json`
- 结构：`{"profile": {...}, "skills": [...], "status": [...], "knowledge": [...], "passwords": [...]}`
- 电子书 PDF 文件不包含在 JSON 备份中，单独打包为 ZIP

## 7. 错误处理策略

### 7.1 异常层次

```
PIMException            # 基础异常
├── DataLoadError       # 数据加载失败
├── DataSaveError       # 数据保存失败
├── RecordNotFoundError # 记录未找到
├── ValidationError     # 数据校验失败
└── BackupError         # 备份/恢复失败
```

### 7.2 处理原则

- 文件 I/O 异常：捕获后在状态栏显示错误提示
- 数据校验失败：在 UI 层以 `messagebox.showerror` 提示用户
- JSON 解析失败：保留原始文件（重命名为 `.bak`），提示用户检查
- PDF 导入失败：校验文件是否为合法 PDF（检查文件头 `%PDF`），失败则提示
- 操作成功：在状态栏显示临时成功提示

## 9. 设计决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| 存储格式 | JSON | 可读性强，Python 标准库支持，调试友好 |
| GUI 框架 | Tkinter | Python 标准库自带，无需安装，跨平台 |
| 知识模型 | 单一 KnowledgeItem + item_type 区分 | 笔记和电子书共用类别和关键词体系，减少重复 |
| PDF 处理 | 调用系统默认应用 | 无需内置 PDF 渲染，保持依赖精简 |
| PDF 存储 | 复制到 Data/books/ | 集中管理，避免源文件被移动/删除导致路径失效 |
| 密码编码 | base64（首版） | 简单实现，后续可升级 AES |
| 数据模型 | dataclass | Python 3.7+ 标准库，减少样板代码 |
| ID 生成 | uuid.uuid4() | 标准库，保证全局唯一 |
| 导航模式 | 左侧导航 + 右侧内容 | 主流布局，扩展性好，操作直观 |
| 知识页面 | ttk.Notebook Tab 切换 | 笔记和电子书共享同一导航项，避免导航栏过长 |
| 弹窗表单 | Toplevel 模态窗口 | 操作聚焦，避免主窗口状态混乱 |
| 原子写入 | 临时文件 + os.replace | 防止写入中断导致数据损坏 |
