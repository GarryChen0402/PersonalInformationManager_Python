# 个人信息管理器 — 需求分析文档

## 1. 项目概述

### 1.1 项目背景

个人在日常工作和生活中积累了大量的碎片化信息，包括基本信息、技能、健康数据、日程安排、知识笔记、电子书等。这些信息分散在不同平台（手机备忘录、Excel、各类APP），缺乏统一管理入口，导致检索困难、数据冗余、维护成本高。

### 1.2 项目目标

开发一款基于 Python + Tkinter 的桌面端个人信息管理器（Personal Information Manager，PIM），提供统一的个人信息管理中心。用户通过可视化窗口完成信息的录入、查询、编辑、删除和统计，数据本地化存储，无需联网。

### 1.3 用户画像

- 希望通过可视化界面集中管理个人数据的用户
- 希望将个人数据本地存储、保护隐私的用户
- 需要轻量级、无外部依赖桌面工具的极简主义者

## 2. 功能需求

### 2.1 核心模块

#### 2.1.1 个人档案模块

管理用户的基本身份信息。

| 功能 | 描述 |
|------|------|
| 查看档案 | 展示个人基本信息（姓名、性别、生日、联系方式等） |
| 编辑档案 | 通过表单修改已有信息字段 |
| 导出档案 | 将个人档案导出为 JSON 文件 |

#### 2.1.2 状态管理模块

记录和追踪个人日常状态与目标。

| 功能 | 描述 |
|------|------|
| 记录状态 | 通过表单添加当日状态记录（心情、精力、专注度等） |
| 查看状态 | 表格展示历史记录，按日期范围筛选 |
| 状态统计 | 按周/月汇总，展示趋势 |

#### 2.1.3 技能管理模块

管理个人技能清单和学习进度。

| 功能 | 描述 |
|------|------|
| 添加技能 | 通过表单录入技能名称、类别、熟练度、学习时长 |
| 查看技能 | 表格展示，按类别或熟练度筛选 |
| 编辑技能 | 双击或选中后编辑技能信息 |
| 删除技能 | 选中后删除技能记录 |
| 技能统计 | 按类别统计技能分布、总学习时长 |

#### 2.1.4 知识管理模块

管理个人的文本笔记和 PDF 电子书，支持分类和关键词检索。

**文本笔记：**

| 功能 | 描述 |
|------|------|
| 创建笔记 | 通过表单录入标题、内容、类别、关键词 |
| 查看笔记 | 按类别或关键词搜索，在详情面板查看内容 |
| 编辑笔记 | 修改已有笔记内容、类别或关键词 |
| 删除笔记 | 选中后删除笔记 |

**PDF 电子书：**

| 功能 | 描述 |
|------|------|
| 导入电子书 | 选择本地 PDF 文件导入，设置标题、类别、关键词 |
| 查看书库 | 以列表或网格展示所有电子书，按类别筛选、关键词搜索 |
| 打开阅读 | 调用系统默认 PDF 阅读器打开电子书 |
| 编辑信息 | 修改电子书的标题、类别、关键词 |
| 删除电子书 | 从书库中移除电子书（可选是否同时删除源文件） |

#### 2.1.5 密码管理模块

安全存储和管理各类账号密码（本地编码）。

| 功能 | 描述 |
|------|------|
| 添加密码 | 通过表单录入平台名称、账号、密码（base64 编码存储） |
| 查看密码 | 表格列出所有平台，支持搜索 |
| 查看详情 | 弹窗显示并解码指定平台的账号密码 |
| 删除密码 | 选中后删除记录 |

### 2.2 系统级功能

| 功能 | 描述 |
|------|------|
| 数据备份 | 将所有数据打包导出为备份文件 |
| 数据恢复 | 从备份文件恢复数据 |
| 数据统计概览 | 仪表盘展示各模块数据总量和概要信息 |

## 3. 非功能需求

| 需求 | 描述 |
|------|------|
| 无外部依赖 | 仅使用 Python 标准库（tkinter、json、os、datetime、base64、shutil 等） |
| 本地存储 | 所有数据以 JSON 文件存储在本地 `Data/` 目录下 |
| PDF 查看 | 调用系统默认应用打开 PDF，程序本身不内置阅读器 |
| 数据安全 | 密码模块使用 base64 编码存储（后续可升级为 AES 加密） |
| GUI 交互 | 基于 Tkinter 的窗口式交互，左侧导航栏 + 右侧内容区 |
| 跨平台 | 兼容 Windows / macOS / Linux |
| 可扩展性 | 模块化架构，新增功能模块不影响已有模块 |
| 中文支持 | 所有界面文案、数据内容使用中文 |
| 响应式布局 | 窗口缩放时界面控件自适应调整 |

## 4. 用户交互流程

```
启动程序 → 主窗口（左侧导航栏 + 右侧内容区）
    左侧导航栏：
    ├── 📋 个人档案 → 右侧显示档案表单
    ├── 📊 状态管理 → 右侧显示状态列表 + 操作按钮
    ├── 🛠 技能管理 → 右侧显示技能表格 + 操作按钮
    ├── 📚 知识管理 → 右侧显示笔记/电子书管理（Tab 切换）
    ├── 🔐 密码管理 → 右侧显示密码列表 + 操作按钮
    ├── 📦 数据管理 → 右侧显示备份/恢复操作面板
    └── 📈 数据概览 → 右侧显示仪表盘统计
```

## 5. 数据目录结构

```
Data/
├── profile.json          # 个人档案
├── status.json           # 状态记录
├── skills.json           # 技能数据
├── knowledge.json        # 知识管理（笔记 + 电子书元数据）
├── passwords.json        # 密码数据
├── books/                # PDF 电子书存放目录
│   ├── Python编程入门.pdf
│   └── 设计模式.pdf
└── backups/              # 备份文件目录
    └── backup_YYYYMMDD_HHMMSS.json
```

## 6. 优先级规划

| 优先级 | 模块 | 说明 |
|--------|------|------|
| P0 | 项目骨架 | 主窗口框架、导航栏、Storage/Config 基础设施 |
| P0 | 个人档案 | 最基础模块，优先实现完整闭环 |
| P1 | 技能管理 | 用户核心诉求 |
| P1 | 状态管理 | 与技能模块并列 |
| P2 | 知识管理 - 笔记 | 日常高频使用 |
| P2 | 知识管理 - 电子书 | PDF 导入与管理 |
| P3 | 密码管理 | 涉及安全考量，放在后期 |
| P3 | 数据管理 | 依赖其他模块完成后实现 |
| P3 | 数据概览仪表盘 | 汇总展示，最后实现 |
