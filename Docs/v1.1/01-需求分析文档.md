# 个人信息管理器 v1.1 — 需求分析文档

## 1. 版本概述

v1.0 已实现 6 个核心模块（个人档案、状态管理、技能管理、知识管理、密码管理、数据备份恢复）+ 仪表盘，共计 36 个功能点，100 项测试，零外部依赖。

v1.1 聚焦于 **安全加固、数据可视化、新增待办模块、全局搜索、数据导入导出增强、UI 改进** 六大方向，在保持零依赖原则的前提下提升系统实用性。

---

## 2. 升级方向

### 2.1 密码安全升级（P0）

v1.0 使用 base64 编码存储密码，仅为混淆而非加密。v1.1 升级为 AES 对称加密，并增加主密码保护。

| 功能 | 描述 |
|------|------|
| AES 加密存储 | 密码字段使用 AES-256-CBC 加密后存储，替换 base64 |
| 主密码验证 | 启动时/查看密码时输入主密码解锁，错误则无法解密 |
| 数据迁移 | 首次启动 v1.1 时自动将 base64 编码密码迁移到 AES 加密 |
| 主密码修改 | 提供主密码修改功能，自动重新加密所有密码条目 |

### 2.2 数据可视化（P0）

当前所有模块均以表格文本形式展示数据，缺少直观的图表呈现。v1.1 使用 Tkinter Canvas 绘制基础图表。

| 功能 | 描述 |
|------|------|
| 状态趋势折线图 | 心情/精力/专注度/睡眠 按时间维度的折线图，支持 7/30/90 天切换 |
| 技能雷达图 | 按类别展示技能熟练度分布的雷达图 |
| 统计柱状图 | 技能类别分布柱状图、知识类别分布柱状图 |
| 仪表盘图表 | 在仪表盘中嵌入迷你趋势图，替代纯文本展示 |

### 2.3 新增模块：待办事项（P1）

个人事务管理是 PIM 的自然延伸，用户可以记录待办任务并追踪完成情况。

| 功能 | 描述 |
|------|------|
| 添加待办 | 通过表单录入标题、描述、优先级（高/中/低）、截止日期、分类标签 |
| 查看待办 | 支持按状态（未完成/已完成/全部）、优先级、分类筛选 |
| 编辑待办 | 修改待办内容、优先级、截止日期 |
| 完成/取消完成 | 勾选标记完成，可取消完成回退到未完成状态 |
| 删除待办 | 删除单条或批量删除已完成待办 |
| 排序功能 | 按优先级、截止日期、创建时间排序 |
| 逾期提醒 | 过期未完成的待办以红色标记 |
| 统计概览 | 总计/未完成/已完成/逾期 数量统计 |

### 2.4 全局搜索（P1）

当前搜索局限于单个模块内部，用户需要记住信息位于哪个模块。全局搜索支持跨模块检索。

| 功能 | 描述 |
|------|------|
| 全局搜索入口 | 在导航栏顶部增加全局搜索框（快捷键 Ctrl+Shift+F） |
| 跨模块检索 | 同时搜索所有模块（技能名称/描述、笔记标题/内容、电子书标题、密码平台/账号、待办标题） |
| 搜索结果聚合 | 按模块分组展示搜索结果，点击可跳转到对应条目 |
| 搜索历史 | 记录最近 10 条搜索关键词 |

### 2.5 数据导入导出增强（P1）

当前仅个人档案支持 JSON 导出，备份为全量 JSON。v1.1 增加按模块的 CSV 导入导出，提升数据可移植性。

| 功能 | 描述 |
|------|------|
| CSV 导出 | 技能、状态、待办、密码（不含密码字段）支持导出为 CSV 文件 |
| CSV 导入 | 技能、待办支持从 CSV 文件批量导入 |
| 各模块 JSON 导出 | Profile、Skill、Status、Knowledge 等各模块均支持独立 JSON 导出 |
| 导出预览 | CSV 导入前预览数据，确认后执行导入 |

### 2.6 UI/UX 改进（P2）

| 功能 | 描述 |
|------|------|
| 主题切换 | 支持浅色/深色主题切换，配置持久化 |
| 键盘快捷键 | 全局快捷键支持（Ctrl+N 新建、Ctrl+F 搜索、Ctrl+S 保存等） |
| 字体缩放 | Ctrl+滚轮 或 Ctrl+/Ctrl- 调整全局字体大小 |
| 导航栏图标 | 导航按钮增加 Unicode 图标前缀，提升视觉辨识度 |
| 表格列宽拖拽 | Treeview 列宽支持用户手动拖拽调整 |
| 确认退出 | 关闭窗口时弹出确认提示，防止误操作 |

### 2.7 代码质量提升（P2）

| 改进项 | 描述 |
|------|------|
| View 基类抽取 | 所有 Page 页面抽取公共基类 `BasePage`，减少重复的 `_get_selected`、`_update_status` 等模式 |
| 类型提示完善 | 所有方法参数和返回值添加完整的类型提示 |
| 魔术数字消除 | 将硬编码的尺寸、颜色、默认值统一抽取到 Config |
| 测试增强 | 新增待办模块测试、AES 加密测试、CSV 导入导出测试、全局搜索测试 |

## 3. 非功能需求（延续 v1.0 + 新增）

| 需求 | 描述 |
|------|------|
| 零外部依赖 | 继续仅使用 Python 标准库（含 `hashlib`、`secrets` 用于 AES） |
| AES 加密 | 使用 `hashlib` + `secrets` 实现 AES-256-CBC，不依赖 `cryptography` 等第三方库 |
| 图表绘制 | 使用 Tkinter `Canvas` 自绘，不引入 matplotlib 等第三方库 |
| 向后兼容 | v1.0 数据可无缝迁移到 v1.1 |
| 配置持久化 | 主题、主密码哈希等配置写入 `Data/config.json` |

## 4. 新增数据模型预览

### 4.1 待办事项（TodoItem）

```python
@dataclass
class TodoItem:
    id: str               # UUID
    title: str
    description: str
    priority: str         # "high" / "mid" / "low"
    due_date: str         # YYYY-MM-DD，可选
    category: str         # 工作/学习/生活/其他
    completed: bool       # 是否完成
    completed_at: str     # 完成时间
    created_at: str
    updated_at: str
```

### 4.2 应用配置（AppConfig）

```python
@dataclass
class AppConfig:
    theme: str            # "light" / "dark"
    font_size: int        # 默认 10，范围 8-16
    master_password_hash: str  # SHA-256 哈希
    last_active_module: str    # 上次使用的模块
    search_history: list[str]  # 最近搜索关键词
```

## 6. 优先级规划

| 优先级 | 升级项 | 说明 |
|--------|--------|------|
| P0 | AES 加密升级 + 主密码 | 安全漏洞修复，最高优先级 |
| P0 | 数据可视化（图表） | 核心体验提升 |
| P1 | 新增待办事项模块 | 新功能模块 |
| P1 | 全局搜索 | 跨模块检索效率提升 |
| P1 | CSV/JSON 导入导出 | 数据可移植性 |
| P2 | UI/UX 改进 | 主题/快捷键/字体 |
| P2 | 代码质量提升 | 重构/类型提示/测试 |

## 7. v1.0 → v1.1 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| AES 密钥管理 | 主密码丢失则数据无法恢复 | 首次设置主密码时强制用户记录恢复码 |
| Canvas 图表性能 | 大数据量下绘制耗时 | 限制图表数据点为最近 90 天，按周聚合 |
| 全局搜索性能 | 跨模块同时搜索耗时 | 各模块搜索异步执行，结果显示有加载状态 |
| 向后兼容性 | 旧数据格式导致加载失败 | 启动时自动检测并迁移数据格式 |
| CSV 编码兼容 | Windows Excel 中文乱码 | CSV 使用 UTF-8 BOM 编码 |
