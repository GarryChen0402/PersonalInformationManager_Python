## 2. 阶段一：安全升级（任务 1.1 ~ 1.6）

**目标**：替换 base64 编码为流密码加密，实现主密码保护，迁移旧数据。

### 任务 1.1 — 实现 Core/Crypto.py

| 产出文件 | 说明 |
|----------|------|
| `Core/Crypto.py` | SHA-256 + XOR 流密码加解密工具 |

**实现要点**：
```python
# SimpleCrypto 类
- derive_key(master_password, salt) → bytes:
  hashlib.pbkdf2_hmac('sha256', ..., salt, 100000)

- encrypt(plaintext, master_password) → str:
  1. 生成 16 字节 salt + 16 字节 nonce
  2. 派生密钥
  3. SHA-256 生成密钥流（counter 模式）
  4. XOR 加密
  5. base64(salt + nonce + ciphertext)

- decrypt(encoded, master_password) → str:
  反向操作，base64 解码后分离 salt/nonce/ciphertext，重建密钥流解密

- verify_token(master_password, token) → bool:
  尝试验证令牌，捕获解码异常返回 False
```

**验收标准**：单元测试加解密往返一致，错误密码解密失败抛异常。

### 任务 1.2 — 实现 Services/CryptoService.py

| 产出文件 | 说明 |
|----------|------|
| `Services/CryptoService.py` | 加密服务（主密码生命周期管理） |

**实现要点**：
```python
class CryptoService:
    _master_password: str | None = None  # 类变量，内存缓存

    @classmethod
    def is_unlocked(cls) → bool:
        """检查主密码是否已解锁"""

    @classmethod
    def unlock(cls, master_password) → bool:
        """验证主密码，成功则缓存"""

    @classmethod
    def lock(cls):
        """清除缓存的主密码"""

    @classmethod
    def get_key(cls) → str:
        """获取当前主密码（未解锁则抛出异常）"""

    @classmethod
    def setup_master_password(cls, password, confirm) → str:
        """首次设置主密码，返回验证令牌"""

    @classmethod
    def change_master_password(cls, old, new):
        """修改主密码，需重新加密所有密码条目"""
```

## 10. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 主密码丢失 | 所有密码数据无法恢复 | 设置主密码时显示恢复码（12 个助记词），提示用户妥善保管 |
| 流密码安全强度 | 不如标准 AES | 文档明确标注安全等级，适用于个人本地使用场景 |
| Canvas 绘图跨平台差异 | 图表外观不一致 | 使用相对坐标 + 百分比计算，避免硬编码像素 |
| 全局搜索性能 | 数据量大时搜索变慢 | 300ms 防抖 + 限制结果 20 条 + 异步搜索 |
| 重构引入回归 bug | 已有功能异常 | 重构前运行全量测试，重构后再次运行确认 |
| 主题切换不完整 | 部分组件颜色异常 | 提供 `apply_theme` 递归方法，遍历所有子控件 |
