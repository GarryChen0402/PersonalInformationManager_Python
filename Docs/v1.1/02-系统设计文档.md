## 3. AES 加密设计

### 3.1 加密方案

使用 Python 标准库手动实现 AES-256-CBC，不依赖第三方库。

```
加密流程:
  1. 用户输入主密码 → PBKDF2 (hashlib.pbkdf2_hmac) 派生 256-bit 密钥
  2. secrets.token_bytes(16) 生成随机 IV
  3. 手动实现 AES-CBC 加密（使用 hashlib + 标准库字节操作）
  4. 存储格式: base64(iv + ciphertext)
```

**简化方案（推荐）**：考虑到手动实现 AES 的复杂性和安全风险，v1.1 采用一种折中方案——使用 Python 标准库中已有的密码学原语实现 AES 加密。通过标准库的 `hashlib` 进行密钥派生，结合 `secrets` 生成安全随机数。

实际上，更务实的做法是利用 Python 标准库中并不直接暴露但可用的加密能力。由于 Python 标准库确实不包含 AES 实现，v1.1 采用以下替代方案：

**最终方案 — 基于 XOR + PBKDF2 的简化加密**：

```python
# Core/Crypto.py
import base64
import hashlib
import secrets
import struct

class SimpleCrypto:
    """使用 SHA-256 + XOR 流密码加密（比 base64 安全，零外部依赖）。"""
    
    @staticmethod
    def derive_key(master_password: str, salt: bytes) -> bytes:
        """PBKDF2 派生 256 位密钥。"""
        return hashlib.pbkdf2_hmac('sha256', master_password.encode(), salt, 100000)
    
    @staticmethod
    def encrypt(plaintext: str, master_password: str) -> str:
        """加密明文，返回 base64 编码密文（含 salt + nonce）。"""
        salt = secrets.token_bytes(16)
        key = SimpleCrypto.derive_key(master_password, salt)
        # 使用 SHA-256 流密钥 XOR
        nonce = secrets.token_bytes(16)
        plain_bytes = plaintext.encode('utf-8')
        # 生成密钥流
        keystream = b''
        counter = 0
        while len(keystream) < len(plain_bytes):
            keystream += hashlib.sha256(key + nonce + struct.pack('>I', counter)).digest()
            counter += 1
        ciphertext = bytes(a ^ b for a, b in zip(plain_bytes, keystream[:len(plain_bytes)]))
        # 存储: salt(16) + nonce(16) + ciphertext
        return base64.b64encode(salt + nonce + ciphertext).decode()
    
    @staticmethod
    def decrypt(encoded: str, master_password: str) -> str:
        """解密密文，返回明文。"""
        data = base64.b64decode(encoded)
        salt = data[:16]
        nonce = data[16:32]
        ciphertext = data[32:]
        key = SimpleCrypto.derive_key(master_password, salt)
        # 重建密钥流
        keystream = b''
        counter = 0
        while len(keystream) < len(ciphertext):
            keystream += hashlib.sha256(key + nonce + struct.pack('>I', counter)).digest()
            counter += 1
        plain = bytes(a ^ b for a, b in zip(ciphertext, keystream[:len(ciphertext)]))
        return plain.decode('utf-8')
```

### 3.2 主密码管理

```
首次设置:
  1. 用户输入主密码 × 2（确认）
  2. 生成随机 salt，PBKDF2 派生密钥
  3. 创建验证令牌: encrypt("PIM_VALID", master_password)
  4. 将 salt + 验证令牌存入 config.json 的 master_password_hash 字段

解锁验证:
  1. 用户输入主密码
  2. 从 config 获取 salt 和验证令牌
  3. 尝试 decrypt(验证令牌, 输入的主密码)
  4. 成功则缓存主密码在内存中（仅在程序运行期间有效）

主密码修改:
  1. 验证旧主密码
  2. 用旧主密码解密所有密码条目
  3. 用新主密码重新加密所有密码条目
  4. 更新验证令牌
```

### 3.3 数据迁移

```
PasswordManager 升级:
  - __init__ 中检测密码是否为 base64 格式（尝试解码后检查是否为可打印 ASCII）
  - 如果是旧格式，在首次解锁后自动重新加密为 AES 格式
  - 迁移完成后标记 config.json 中 migration.password = True
```

## 8. BasePage 重构设计

### 8.1 动机

当前 6 个 Page 类中都存在重复模式：
- `_get_selected()` — 获取 Treeview 选中行
- `_update_status()` — 转发状态消息
- `_build_context_menu()` — 右键菜单构建

### 8.2 BasePage 设计

```python
class BasePage(tk.Frame):
    """所有功能页面的基类。"""

    def __init__(self, parent, set_status):
        super().__init__(parent, bg="#ffffff")
        self.set_status = set_status

    def _get_selected(self, tree, manager, id_field="id"):
        """通用选中行获取。"""
        selection = tree.selection()
        if not selection:
            messagebox.showinfo("提示", "请先选中一条记录")
            return None
        return manager.get_by_id(selection[0])

    def _update_status(self, message: str):
        if self.set_status:
            self.set_status(message)

    def _clear_tree(self, tree):
        for item in tree.get_children():
            tree.delete(item)

    def _build_context_menu(self, tree, items: list[tuple[str, callable]]):
        """items: [("编辑", callback), ("删除", callback), ...]"""
        menu = tk.Menu(self, tearoff=0)
        for i, (label, cmd) in enumerate(items):
            if label == "---":
                menu.add_separator()
            else:
                menu.add_command(label=label, command=cmd)
        tree.bind("<Button-3>", lambda e: self._show_menu(e, tree, menu))
        return menu
```

## 11. 设计决策记录（新增）

| 决策 | 选择 | 原因 |
|------|------|------|
| 加密方案 | SHA-256 流密码（XOR + PBKDF2） | Python 标准库不含 AES，手动实现 AES 块密码复杂度高且易出错；流密码方案简单可靠，安全性远超 base64 |
| 图表实现 | Tkinter Canvas 自绘 | 零依赖原则，matplotlib 为重型第三方库 |
| 全局搜索位置 | 导航栏顶部 | 全局入口，不占用内容区空间 |
| 配置存储 | 独立 config.json | 与业务数据分离，便于未来迁移 |
| BasePage 模式 | 组合式基类（非强制） | 保持灵活性，不影响不需要这些方法的页面 |
| 主密码 | PBKDF2 100000 轮迭代 | 防暴力破解，100k 轮在用户感知速度与安全性间平衡 |
| CSV 编码 | UTF-8 BOM | 确保 Windows Excel 正确识别中文 |
