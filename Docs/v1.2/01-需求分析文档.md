# 个人信息管理器 v1.2 — 需求分析文档

## 1. 版本概述

v1.1 已实现 7 个核心模块（个人档案、状态管理、技能管理、知识管理、待办事项、密码管理、数据备份恢复）+ 仪表盘 + 全局搜索 + Canvas 图表 + CSV 导入导出，共计 50+ 功能点，159 项测试，零外部依赖。

v1.2 聚焦于 **安全加固、新增习惯追踪与日记模块、日历热力图、数据导出增强、测试覆盖补全、UI 细化** 六大方向，在保持零依赖原则的前提下持续提升系统实用性与代码质量。

---

## 2. 升级方向

### 2.1 密码安全加固（P0）

v1.1 使用 PBKDF2 + SHA-256 XOR 流密码加密，但缺少消息认证码（MAC），无法检测密文是否被篡改。v1.2 增加 HMAC 认证和自动锁定机制。

| 功能 | 描述 |
|------|------|
| HMAC 认证加密 | 加密流程升级为 Encrypt-then-MAC：生成密文后附加 HMAC-SHA256 签名，解密前先验证签名 |
| 自动锁定 | 用户可配置自动锁定时间（5分钟/15分钟/30分钟/从不），超时后自动清除内存中的主密码 |
| 密码强度指示 | 设置/修改主密码时显示密码强度（弱/中/强），基于长度和字符多样性 |
| 错误次数限制 | 连续 5 次解锁失败后锁定 30 秒，防止暴力破解 |
| 密文格式版本化 | 加密数据增加版本头（v1/v2），支持未来加密算法升级 |

### 2.2 新增模块：习惯追踪（P1）

习惯追踪是个人管理的自然延伸，帮助用户建立和维持良好习惯。

| 功能 | 描述 |
|------|------|
| 习惯定义 | 创建习惯：名称、描述、频率（每天/每周/自定义天数）、目标次数、分类标签 |
| 每日打卡 | 日历视图点击日期完成打卡，支持撤销 |
| 连续统计 | 当前连续天数、最长连续天数、总打卡次数、完成率 |
| 习惯列表 | 表格展示所有习惯，显示今日是否已打卡、当前连续天数 |
| 日历热力图 | 每个习惯独立显示年度打卡热力图（GitHub 贡献图风格） |
| 习惯编辑 | 修改习惯名称、频率、目标次数 |
| 习惯归档 | 暂停不再追踪的习惯（归档而非删除，保留历史数据） |
| 统计概览 | 总习惯数、活跃数、今日打卡率、全习惯平均完成率 |

### 2.3 新增模块：日记（P1）

日记模块提供按日期的自由文本记录，与状态模块的情绪数据形成互补。

| 功能 | 描述 |
|------|------|
| 日历导航 | 左侧日历控件，点击日期查看/编辑当天日记，有日记的日期显示标记点 |
| 日记编辑 | 标题 + 正文（多行文本），自动保存（离开页面或切换日期时保存） |
| 日记列表 | 按时间倒序展示所有日记，支持关键词搜索 |
| 情绪关联 | 若当天有状态记录，自动在日记页显示当天心情/精力/专注度评分 |
| 字数统计 | 显示当前日记字数和总字数量 |
| 导出功能 | 单篇导出为 TXT/Markdown，批量导出为 Markdown |
| 统计概览 | 总日记数、总字数、最早/最晚日记日期、本月日记数 |

### 2.4 日历热力图组件（P1）

状态模块当前使用折线图展示趋势，缺少直观的年度概览。新增日历热力图组件。

| 功能 | 描述 |
|------|------|
| 年度热力图 | GitHub 贡献图风格，52 周 × 7 天方格矩阵，颜色深浅表示数值高低 |
| 多指标切换 | 支持切换显示心情/精力/专注度/睡眠的热力图 |
| 月份标签 | 左侧显示月份标签 |
| 悬停提示 | 鼠标悬停显示具体日期和数值 |
| 集成位置 | 状态模块嵌入热力图，习惯模块每个习惯独立显示 |

### 2.5 数据导出增强（P1）

当前支持 JSON 和 CSV 导出，v1.2 增加 Markdown 和 iCalendar 格式。

| 功能 | 描述 |
|------|------|
| 笔记 Markdown 导出 | 知识模块的笔记支持导出为 Markdown 文件（含 frontmatter 元数据） |
| 日记 Markdown 导出 | 日记支持单篇或批量导出为 Markdown |
| 待办 iCalendar 导出 | 待办事项导出为 .ics 文件，可导入 Google Calendar / Apple Calendar |
| 全量数据打包 | 一键导出所有模块数据为单个 JSON 文件（含时间戳和版本信息），便于迁移 |
| 导出进度提示 | 大数据量导出时显示进度条或状态提示 |

## 4. 新增数据模型预览

### 4.1 习惯（Habit）

```python
@dataclass
class Habit:
    id: str               # UUID
    name: str             # 习惯名称
    description: str      # 描述
    frequency: str        # "daily" / "weekly" / "custom"
    custom_days: int      # 自定义频率天数（frequency="custom" 时使用）
    target_count: int     # 每次目标次数（默认 1）
    category: str         # 健康/学习/工作/生活/其他
    color: str            # 热力图主题色（默认蓝色）
    archived: bool        # 是否归档
    created_at: str
    updated_at: str
```

### 4.2 习惯打卡记录（HabitRecord）

```python
@dataclass
class HabitRecord:
    id: str               # UUID
    habit_id: str         # 关联习惯 ID
    date: str             # 日期 YYYY-MM-DD
    count: int            # 完成次数
    note: str             # 备注
    created_at: str
```

### 4.3 日记（JournalEntry）

```python
@dataclass
class JournalEntry:
    id: str               # UUID
    date: str             # 日期 YYYY-MM-DD（唯一，同一天只存一篇）
    title: str            # 标题
    content: str          # 正文
    word_count: int       # 字数（保存时自动计算）
    created_at: str
    updated_at: str
```

| 优先级 | 升级项 | 说明 |

## 7. v1.1 → v1.2 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 加密格式升级兼容 | 旧密文无法解密 | 密文增加版本头（v1/v2），v2 解密失败回退 v1 格式尝试 |
| 热力图渲染性能 | 365 天方格绘制耗时 | 使用 Canvas 矩形批量绘制，仅绘制可视区域 |
| 习惯数据膨胀 | 多年打卡记录导致文件过大 | 打卡记录按年分文件存储（habit_records_2026.json） |
| 日记数据安全 | 日记含敏感隐私信息 | 日记模块可选加密存储（复用 CryptoService） |
| 新模块破坏已有功能 | 导航栏过长、窗口拥挤 | 导航栏支持折叠 + 滚动，新模块可配置显示/隐藏 |
| iCalendar 兼容性 | 不同日历应用解析差异 | 遵循 RFC 5545 标准，使用标准库 `textwrap` 控制行宽 |
