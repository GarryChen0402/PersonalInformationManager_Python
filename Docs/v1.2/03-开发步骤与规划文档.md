## 2. 阶段一：密码安全加固（任务 1.1 ~ 1.5）

**目标**：升级加密方案支持 HMAC 认证，实现自动锁定，添加密码强度检测。

### 任务 1.1 — 升级 Core/Crypto.py（HMAC 认证加密）

| 产出文件 | 说明 |
|----------|------|
| `Core/Crypto.py` | 新增 HMAC 认证 + 版本化密文格式 |

**实现要点**：

```python
# 变更点
1. derive_keys(password, salt) → (enc_key, hmac_key):
   PBKDF2 派生 64 字节，前 32 字节 enc_key，后 32 字节 hmac_key

2. encrypt(plaintext, password, version="v2") → str:
   - salt(16) + nonce(16) 不变
   - 派生 enc_key + hmac_key
   - XOR 加密得 ciphertext
   - hmac = HMAC-SHA256(hmac_key, nonce + ciphertext)
   - 返回 "v2:" + base64(salt + nonce + ciphertext + hmac)

3. decrypt(encoded, password) → str:
   - 检测版本头 "v2:" 或 "v1:"（无版本头视为 v1）
   - v2: 提取 hmac，验证 HMAC 签名，失败抛 CryptoError
   - v1: 跳过 HMAC 验证，直接解密（向后兼容）
   - 重构提取 _encrypt_v1 / _decrypt_v1 / _encrypt_v2 / _decrypt_v2

4. create_token(password) → str:
   使用 v2 格式加密固定字符串 "PIM_TOKEN_V2"

5. verify_token(password, token) → bool:
   尝试 v2 解密，失败则尝试 v1 解密

6. get_password_strength(password) → dict:
   基于长度、大小写、数字、特殊字符评分
   score 0-4 → level: "weak"/"medium"/"strong"
```

**验收标准**：
- v2 加密→解密往返正确
- v2 密文被篡改后解密抛出 CryptoError
- v1 密文（无版本头）仍可正常解密
- 密码强度评分逻辑正确
- 新增 15 个单元测试全部通过

**连续天数算法**（在 `get_streak` 中实现）：

```python
def _calculate_streak(records, frequency, custom_days):
    """
    records: 按日期排序的打卡记录
    从今天往回遍历，检查每个周期是否有打卡
    返回 (current_streak, longest_streak)
    """
    today = datetime.date.today()
    current = 0
    longest = 0
    temp_streak = 0
    check_date = today

    while True:
        if frequency == "daily":
            period_start = check_date
            period_end = check_date
        elif frequency == "weekly":
            period_start = check_date - datetime.timedelta(days=check_date.weekday())
            period_end = period_start + datetime.timedelta(days=6)
        else:  # custom
            period_start = check_date
            period_end = check_date  # 简化：检查当天

        has_record = any(
            datetime.date.fromisoformat(r["date"]) >= period_start and
            datetime.date.fromisoformat(r["date"]) <= period_end
            for r in records
        )

        if has_record:
            temp_streak += 1
        else:
            longest = max(longest, temp_streak)
            if check_date == today:
                current = temp_streak
            temp_streak = 0

        check_date -= datetime.timedelta(days=1)
        if check_date < today - datetime.timedelta(days=366):
            break

    return current, max(longest, temp_streak)
```

```python
def export_icalendar(self, output_path, todo_ids=None):
    """导出待办为 .ics 文件。"""
    todos = self.get_all()
    if todo_ids:
        todos = [t for t in todos if t.id in todo_ids]

    lines = [
        "BEGIN:VCALENDAR",
        "VERSION:2.0",
        "PRODID:-//PIM//PersonalInformationManager//CN",
        "X-WR-CALNAME:PIM 待办事项",
    ]

    for todo in todos:
        lines.extend([
            "BEGIN:VTODO",
            f"UID:{todo.id}",
            f"SUMMARY:{todo.title}",
            f"DESCRIPTION:{todo.description}",
            f"PRIORITY:{_priority_to_int(todo.priority)}",  # high=1, mid=5, low=9
            f"DTSTART;VALUE=DATE:{todo.due_date.replace('-', '')}" if todo.due_date else "",
            f"STATUS:{'COMPLETED' if todo.completed else 'NEEDS-ACTION'}",
            f"CATEGORIES:{todo.category}",
            "END:VTODO",
        ])

    lines.append("END:VCALENDAR")

    # 使用 textwrap 控制 75 字符行宽
    content = "\r\n".join(lines)
    with open(output_path, "w", encoding="utf-8") as f:
        f.write(content)
```

## 10. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| HMAC 密钥派生变更 | 旧 v1 格式无法用新代码解密 | 保留 `_decrypt_v1` 方法，版本头自动路由 |
| 连续天数计算边界 | 跨年/闰年/时区导致统计错误 | 统一使用 `datetime.date` 处理，编写 10+ 边界测试 |
| 热力图性能 | 365 天方格 + tooltip 更新导致卡顿 | 方格仅 12×12 px，一次性绘制，tooltip 仅在 hover 时更新 |
| 日记数据膨胀 | 多年日记导致 JSON 文件过大 | 建议按年分文件（v1.3 规划），当前限制在 < 1MB 合理范围 |
| 导航栏过长 | 9 个模块按钮 + 搜索框超出屏幕 | 折叠功能 + 按钮区域可滚动 |
| 新模块破坏现有功能 | 重构引入回归 | 阶段二先建立测试基础设施，各阶段结束立即运行全量测试 |
| CSV 导入破坏 | schema 变更后旧 CSV 导入失败 | CSV 导入保持字段可选，缺失字段使用默认值 |
| 主题覆盖不全 | 新增组件遗漏主题适配 | ChartWidgets 和 Widgets 统一使用 ChartBase 的 `self.colors` 属性 |
