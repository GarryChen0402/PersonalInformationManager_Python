### 任务 2.2 — 重写 ChartWidgets.py（图表组件）

| 产出文件 | 说明 |
|----------|------|
| `Views/ChartWidgets.py` | ChartBase, LineChart, BarChart, RadarChart, MiniChart, CalendarHeatmap |

**图表映射**：

| Tkinter Canvas API | PySide6 QPainter API | 说明 |
|-------------------|---------------------|------|
| `create_line(x1,y1,x2,y2,...)` | `drawPolyline(QPointF[])` | 折线 |
| `create_rectangle(x1,y1,x2,y2)` | `fillRect(QRectF)` | 矩形填充 |
| `create_polygon(points)` | `drawPolygon(QPointF[])` | 多边形 |
| `create_oval(x1,y1,x2,y2)` | `drawEllipse(QPointF, rx, ry)` | 圆点 |
| `create_text(x,y,text=...)` | `drawText(QRectF, flags, text)` | 文本 |
| `itemconfig(item, fill=color)` | 不需要（直接 repaint） | 颜色更新 |
| Canvas `configure(bg=...)` | `painter.fillRect(rect, color)` | 背景色 |
| `<Motion>` 事件 | `mouseMoveEvent(QMouseEvent)` | 鼠标追踪 |
| `coords(item, x, y)` | 不需要（逻辑层计算，绘制层直接用新坐标） | 坐标更新 |

**关键实现差异**：
- Tkinter Canvas 是"保留模式"（创建图形对象后修改属性），QPainter 是"即时模式"（每次 paintEvent 重新绘制全部内容）
- `self.update()` 触发 Qt 的 `paintEvent()`，等同于 Canvas 的重绘
- 主题颜色通过 `self.colors` 字典注入，在 `_draw()` 中读取

**ChartBase 实现**：
```python
class ChartBase(QWidget):
    def __init__(self, parent=None, title=""):
        super().__init__(parent)
        self.title = title
        self.colors = {}
        self.setMinimumSize(400, 250)

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.Antialiasing)
        self._draw(painter)
        painter.end()

    def _draw(self, painter):
        pass  # 子类实现
```

**验收标准**：
- LineChart 正确绘制多系列折线 + 图例 + 数据点
- BarChart 正确绘制分组柱状图
- RadarChart 正确绘制多边形雷达图
- MiniChart 正确绘制迷你趋势图
- CalendarHeatmap 正确绘制年度热力图 + hover tooltip
- 所有图表支持主题颜色切换（repaint 后颜色变化）

## 10. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| PySide6 安装失败 | 无法启动开发 | 确认 Python 3.10+ 环境；使用 `pip install pyside6`；备选 PyQt6 |
| Qt Stylesheet 语法错误 | 控件显示异常 | 逐主题测试；保留最小可用主题作为回退 |
| QPainter 图表绘制差异 | 图表外观与 Tkinter 有差异 | 保持数学计算逻辑不变，仅替换绘制 API |
| 信号槽连接错误 | 交互功能失效 | 每个页面完成后独立交互测试 |
| QTableWidget 排序与行颜色冲突 | 排序后颜色错乱 | 使用 QTableWidgetItem.setData(BackgroundRole) 而非 setBackground |
| 打包体积增大 | PyInstaller 打包后体积 50MB+ | 可接受：现代桌面应用常态；使用 `--onedir` 模式 |
| 学习成本 | 开发进度慢于预期 | PySide6 API 文档完善；原 Tkinter 代码逻辑可参考 |
| 依赖引入争议 | 破坏"零依赖"原则 | README 明确说明；仅引入 1 个依赖（PySide6）；选 LGPL 协议 |
