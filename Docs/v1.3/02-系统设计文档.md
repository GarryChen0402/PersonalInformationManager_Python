# 个人信息管理器 v1.3 — 系统设计文档

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 三层不变 | Core、Model、Service 三层代码零变更，仅 View 层重写 |
| 接口兼容 | View 层对外接口（`set_status` 回调、`navigate` 回调、Manager 实例化）保持相同签名 |
| 组件化 | 将 Tkinter 的自绘组件（Widgets.py/ChartWidgets.py）映射为 PySide6 等价组件 |
| 关注点分离 | 继续四层架构（View → Service → Model → Storage） |
| 信号槽解耦 | 使用 Qt Signals & Slots 替代 Tkinter 的 `command=` 和 `bind()` |
| 渐进迁移 | 按基础设施 → 核心模块 → 功能模块 → 图表 → 主题的顺序逐阶段迁移 |

## 3. Tkinter → PySide6 控件映射表

### 3.1 核心控件映射

| Tkinter 控件 | PySide6 控件 | 说明 |
|-------------|-------------|------|
| `tk.Tk()` | `QApplication` + `QMainWindow` | Qt 分离了应用和窗口概念 |
| `tk.Frame` | `QWidget` / `QFrame` | QFrame 支持边框样式（StyledPanel/Raised/Sunken 等） |
| `ttk.Frame` | `QWidget` | 普通容器 |
| `ttk.Label` | `QLabel` | 文本/图片/富文本显示 |
| `ttk.Button` | `QPushButton` | 支持图标+文字+菜单 |
| `ttk.Entry` | `QLineEdit` | 单行输入，原生 placeholder |
| `tk.Text` | `QTextEdit` / `QPlainTextEdit` | QTextEdit 支持富文本；QPlainTextEdit 纯文本更高效 |
| `ttk.Treeview` | `QTableWidget` / `QTreeWidget` | QTableWidget 用于表格式数据；QTreeWidget 用于树形数据 |
| `ttk.Notebook` | `QTabWidget` | 标签页容器 |
| `ttk.Combobox` | `QComboBox` | 下拉选择框 |
| `ttk.Checkbutton` | `QCheckBox` | 复选框 |
| `ttk.Radiobutton` | `QRadioButton` | 单选按钮 |
| `ttk.Scrollbar` | `QScrollBar` | 滚动条 |
| `ttk.Progressbar` | `QProgressBar` | 进度条 |
| `ttk.Separator` | `QFrame` (HLine/VLine) | 分隔线 |
| `tk.Canvas` | `QWidget` + `paintEvent()` + `QPainter` | 自定义绘制 |
| `tk.Toplevel` | `QDialog` | 模态/非模态对话框 |
| `tk.Menu` | `QMenuBar` + `QMenu` + `QAction` | 菜单系统 |

### 3.2 布局映射

| Tkinter | PySide6 | 说明 |
|---------|---------|------|
| `pack(side=TOP, fill=X)` | `QVBoxLayout` | 垂直堆叠 |
| `pack(side=LEFT, fill=Y)` | `QHBoxLayout` | 水平排列 |
| `grid(row=0, column=0)` | `QGridLayout` | 网格布局 |
| `pack_forget()` / `pack()` | `QStackedWidget.setCurrentWidget()` | 页面切换 |
| `PanedWindow` | `QSplitter` | 可拖拽分割面板 |
| 无直接对应 | `QFormLayout` | 标签-字段对布局（ProfilePage 适用） |
| 无直接对应 | `QStackedLayout` | 堆叠布局 |

### 3.3 事件/回调映射

| Tkinter | PySide6 | 说明 |
|---------|---------|------|
| `command=callback` | `clicked.connect(callback)` | 按钮点击 |
| `bind("<KeyRelease>", cb)` | `textChanged.connect(cb)` | 文本变更 |
| `bind("<Double-1>", cb)` | `doubleClicked.connect(cb)` | 双击 |
| `bind("<Button-3>", cb)` | `customContextMenuRequested` | 右键菜单 |
| `bind("<Motion>", cb)` | `mouseMoveEvent()` | 鼠标移动 |
| `root.after(ms, cb)` | `QTimer.singleShot(ms, cb)` | 一次性定时器 |
| `root.after(ms, cb)` (循环) | `QTimer` + `timeout.connect(cb)` | 循环定时器 |
| `StringVar.trace("w", cb)` | 不需要（信号槽直接触发） | 变量追踪 |
| `protocol("WM_DELETE_WINDOW", cb)` | `closeEvent()` | 窗口关闭事件 |

```python
from PySide6.QtWidgets import QMainWindow, QStackedWidget, QStatusBar, QSplitter
from PySide6.QtCore import Qt, QTimer
from PySide6.QtGui import QAction, QKeySequence

class App(QMainWindow):
    """PIM 主窗口。"""

    def __init__(self):
        super().__init__()
        self.setWindowTitle("个人信息管理器 v1.3")
        self.setMinimumSize(800, 600)

        # 配置管理器
        self.config_manager = ConfigManager()

        # 页面容器
        self.stack = QStackedWidget()

        # 左侧导航 + 搜索
        self.nav_frame = NavFrame(self._on_nav_select, self._on_global_search)

        # 主布局：QSplitter(导航栏 | 内容区)
        self.splitter = QSplitter(Qt.Horizontal)
        self.splitter.addWidget(self.nav_frame)
        self.splitter.addWidget(self.stack)
        self.splitter.setStretchFactor(0, 0)  # 导航栏不拉伸
        self.splitter.setStretchFactor(1, 1)  # 内容区拉伸
        self.setCentralWidget(self.splitter)

        # 状态栏
        self.status_bar = QStatusBar()
        self.setStatusBar(self.status_bar)

        # 时钟标签
        self.clock_label = QLabel()
        self.status_bar.addPermanentWidget(self.clock_label)

        # 初始化页面
        self._init_pages()
        self._init_shortcuts()
        self._apply_theme()
        self._restore_window_geometry()
        self._start_clock()

    def set_status(self, text: str):
        """供子页面调用的状态栏更新方法。"""
        self.status_bar.showMessage(text, 5000)

    def _init_pages(self):
        """创建所有页面并添加到 QStackedWidget。"""
        self.pages = {}
        page_classes = {
            "dashboard":  lambda: DashboardPage(self.stack, self.set_status, self._navigate_to),
            "profile":    lambda: ProfilePage(self.stack, self.set_status),
            "status":     lambda: StatusPage(self.stack, self.set_status),
            "skill":      lambda: SkillPage(self.stack, self.set_status),
            "knowledge":  lambda: KnowledgePage(self.stack, self.set_status),
            "todo":       lambda: TodoPage(self.stack, self.set_status),
            "habit":      lambda: HabitPage(self.stack, self.set_status),
            "journal":    lambda: JournalPage(self.stack, self.set_status),
            "password":   lambda: PasswordPage(self.stack, self.set_status),
            "backup":     lambda: BackupPage(self.stack, self.set_status),
        }
        for name, factory in page_classes.items():
            page = factory()
            self.pages[name] = page
            self.stack.addWidget(page)

    def _navigate_to(self, page_name: str):
        """导航到指定页面。"""
        if page_name in self.pages:
            self.stack.setCurrentWidget(self.pages[page_name])
            # 更新导航栏选中状态
            self.nav_frame.set_active(page_name)

    def _init_shortcuts(self):
        """初始化键盘快捷键。"""
        # Ctrl+T: 切换主题
        switch_theme = QAction("切换主题", self)
        switch_theme.setShortcut(QKeySequence("Ctrl+T"))
        switch_theme.triggered.connect(self._cycle_theme)
        self.addAction(switch_theme)

        # Ctrl+F: 聚焦全局搜索
        focus_search = QAction("全局搜索", self)
        focus_search.setShortcut(QKeySequence("Ctrl+F"))
        focus_search.triggered.connect(self.nav_frame.focus_search)
        self.addAction(focus_search)

        # Ctrl+1~9: 导航到模块
        nav_order = ["dashboard", "profile", "status", "skill", "knowledge",
                     "todo", "habit", "journal", "password"]
        for i, name in enumerate(nav_order):
            action = QAction(f"导航到{name}", self)
            action.setShortcut(QKeySequence(f"Ctrl+{i+1}"))
            action.triggered.connect(lambda checked, n=name: self._navigate_to(n))
            self.addAction(action)

    def _apply_theme(self):
        """应用主题样式表。"""
        theme_name = self.config_manager.get("theme", "light")
        stylesheet = THEMES.get(theme_name, THEMES["light"])
        self.setStyleSheet(stylesheet)

    def _cycle_theme(self):
        """循环切换主题。"""
        themes = ["light", "dark", "solarized_light", "solarized_dark", "nord"]
        current = self.config_manager.get("theme", "light")
        next_idx = (themes.index(current) + 1) % len(themes)
        self.config_manager.set("theme", themes[next_idx])
        self._apply_theme()

    def _restore_window_geometry(self):
        """恢复窗口几何状态。"""
        geo = self.config_manager.get("window_geometry", "")
        if geo:
            try:
                self.restoreGeometry(bytes.fromhex(geo))
            except Exception:
                pass

    def _save_window_geometry(self):
        """保存窗口几何状态。"""
        geo = self.saveGeometry().hex()
        self.config_manager.set("window_geometry", geo)

    def _start_clock(self):
        """状态栏时钟，每分钟更新。"""
        def update():
            self.clock_label.setText(
                datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
            )
        update()
        self.clock_timer = QTimer()
        self.clock_timer.timeout.connect(update)
        self.clock_timer.start(60000)

    def closeEvent(self, event):
        """窗口关闭时保存状态。"""
        self._save_window_geometry()
        event.accept()

from PySide6.QtWidgets import QWidget, QVBoxLayout, QListWidget, QListWidgetItem, QPushButton
from PySide6.QtCore import Qt, Signal

class NavFrame(QWidget):
    """左侧导航栏。"""
    navigated = Signal(str)  # 导航信号

    NAV_ITEMS = [
        ("dashboard",  "📈 数据概览", "📈"),
        ("profile",    "👤 个人档案", "👤"),
        ("status",     "📊 状态管理", "📊"),
        ("skill",      "🛠 技能管理", "🛠"),
        ("knowledge",  "📚 知识管理", "📚"),
        ("todo",       "✅ 待办事项", "✅"),
        ("habit",      "🔥 习惯追踪", "🔥"),
        ("journal",    "📝 日记",     "📝"),
        ("password",   "🔐 密码管理", "🔐"),
        ("backup",     "📦 数据管理", "📦"),
    ]

    def __init__(self, on_navigate, on_search=None):
        super().__init__()
        self.setMinimumWidth(150)
        self.setMaximumWidth(300)

        layout = QVBoxLayout(self)
        layout.setContentsMargins(4, 4, 4, 4)
        layout.setSpacing(4)

        # 全局搜索框（可选）
        if on_search:
            self.search_bar = GlobalSearchBar(self, on_search)
            layout.addWidget(self.search_bar)

        # 折叠按钮
        self.collapse_btn = QPushButton("◀")
        self.collapse_btn.setFixedWidth(30)
        self.collapse_btn.clicked.connect(self._toggle_collapse)
        layout.addWidget(self.collapse_btn)

        # 导航列表
        self.nav_list = QListWidget()
        for key, text, icon in self.NAV_ITEMS:
            item = QListWidgetItem(f"{icon}  {text}")
            item.setData(Qt.UserRole, key)
            self.nav_list.addItem(item)
        self.nav_list.currentRowChanged.connect(self._on_item_clicked)
        layout.addWidget(self.nav_list)

        self.collapsed = False

    def _on_item_clicked(self, row):
        if row >= 0:
            key = self.nav_list.item(row).data(Qt.UserRole)
            self.navigated.emit(key)

    def set_active(self, page_name: str):
        """设置当前选中项（不触发信号）。"""
        for i in range(self.nav_list.count()):
            if self.nav_list.item(i).data(Qt.UserRole) == page_name:
                self.nav_list.blockSignals(True)
                self.nav_list.setCurrentRow(i)
                self.nav_list.blockSignals(False)
                break

    def _toggle_collapse(self):
        """折叠/展开导航栏。"""
        if self.collapsed:
            # 展开：显示完整文本
            for i in range(self.nav_list.count()):
                key, full_text, icon = self.NAV_ITEMS[i]
                self.nav_list.item(i).setText(f"{icon}  {full_text}")
            self.setMinimumWidth(150)
            self.collapse_btn.setText("◀")
        else:
            # 折叠：仅显示图标
            for i in range(self.nav_list.count()):
                key, full_text, icon = self.NAV_ITEMS[i]
                self.nav_list.item(i).setText(icon)
            self.setMinimumWidth(50)
            self.collapse_btn.setText("▶")
        self.collapsed = not self.collapsed

    def focus_search(self):
        """聚焦搜索框。"""
        if hasattr(self, 'search_bar'):
            self.search_bar.search_input.setFocus()
```

class BasePage(QWidget):

    - QTableWidget + 内置排序
    - 统计栏
    - 右键上下文菜单
    - 选中行高亮
    - TreeView 清除/刷新
    """

    def __init__(self, parent=None, set_status=None):
        super().__init__(parent)
        self._set_status = set_status

        self.layout = QVBoxLayout(self)
        self.layout.setContentsMargins(0, 0, 0, 0)

        # 表格（子类填充列定义）
        self.table = QTableWidget()
        self.table.setSelectionBehavior(QTableWidget.SelectRows)  # 选中整行
        self.table.setSelectionMode(QTableWidget.SingleSelection)
        self.table.setEditTriggers(QTableWidget.NoEditTriggers)   # 只读
        self.table.setAlternatingRowColors(True)                   # 交替行色
        self.table.verticalHeader().setVisible(False)              # 隐藏行号
        self.table.horizontalHeader().setStretchLastSection(True)  # 最后一列拉伸
        self.table.horizontalHeader().setSortIndicatorShown(True)  # 显示排序箭头

        # 启用内置排序
        self.table.setSortingEnabled(True)

        # 右键菜单
        self.table.setContextMenuPolicy(Qt.CustomContextMenu)
        self.table.customContextMenuRequested.connect(self._on_context_menu)

        self.layout.addWidget(self.table)

        # 统计栏（子类设置内容）
        self.stats_bar = QWidget()
        self.stats_layout = QHBoxLayout(self.stats_bar)
        self.layout.addWidget(self.stats_bar)

    def _set_selected_id(self, item_id: str):
        """存储当前选中项的 ID。"""
        self._selected_id = item_id

    def _get_selected_id(self) -> str | None:
        """获取当前选中行的 ID。"""
        row = self.table.currentRow()
        if row >= 0:
            id_item = self.table.item(row, 0)
            if id_item:
                return id_item.data(Qt.UserRole)  # ID 存储在 UserRole 中
        return None

    def _on_context_menu(self, pos):
        """右键上下文菜单（子类重写以添加菜单项）。"""
        menu = self._build_context_menu()
        if menu:
            menu.exec(self.table.viewport().mapToGlobal(pos))

    def _build_context_menu(self) -> QMenu | None:
        """子类重写以构建自定义右键菜单。"""
        return None

    def emit_status(self, text: str):
        """发送状态栏消息。"""
        if self._set_status:
            self._set_status(text)

class FormDialog(QDialog):
    """通用表单对话框。"""
    def __init__(self, parent=None, title="", fields=None):
        super().__init__(parent)
        self.setWindowTitle(title)
        self.setModal(True)

        layout = QFormLayout(self)
        self.widgets = {}

        for field in fields:
            label = field.get("label", "")
            widget_type = field.get("type", "text")
            if widget_type == "text":
                w = QLineEdit()
                w.setText(field.get("default", ""))
            elif widget_type == "combo":
                w = QComboBox()
                w.addItems(field.get("options", []))
            elif widget_type == "date":
                w = QDateEdit()
                w.setCalendarPopup(True)
                w.setDate(QDate.currentDate())
            elif widget_type == "textarea":
                w = QTextEdit()  # Qt 多行文本
            else:
                w = QLineEdit()
            self.widgets[field["key"]] = w
            layout.addRow(label, w)

        # 按钮
        buttons = QDialogButtonBox(QDialogButtonBox.Ok | QDialogButtonBox.Cancel)
        buttons.accepted.connect(self.accept)
        buttons.rejected.connect(self.reject)
        layout.addRow(buttons)

    def get_data(self) -> dict:
        """获取表单数据。"""
        data = {}
        for key, w in self.widgets.items():
            if isinstance(w, QLineEdit):
                data[key] = w.text()
            elif isinstance(w, QComboBox):
                data[key] = w.currentText()
            elif isinstance(w, QDateEdit):
                data[key] = w.date().toString("yyyy-MM-dd")
            elif isinstance(w, QTextEdit):
                data[key] = w.toPlainText()
        return data

## 7. 设计决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| Qt 绑定选择 | PySide6 | LGPL 协议友好；Qt 官方维护；Pythonic Snake case API |
| 安装方式 | `pip install pyside6` | 标准方式，PyInstaller 打包支持成熟 |
| 图表实现 | QPainter 自绘 | 保留灵活性；不引入 Qt Charts 额外依赖；功能与 Canvas 对等 |
| 主题实现 | Qt Stylesheet (QSS) | 比 Tkinter 手动字典配置更简洁；支持选择器/伪状态/继承 |
| 页面切换 | QStackedWidget | Qt 原生页面栈，替代 pack_forget/pack |
| 布局方式 | QVBoxLayout/QHBoxLayout/QGridLayout | 自动适应窗口大小；支持 stretch factor |
| 导航栏折叠 | QListWidget + 动态修改文本 | QSplitter 替代 Tkinter PanedWindow |
| 表格排序 | QTableWidget.setSortingEnabled(True) | Qt 内置排序，极大简化代码 |
| 窗口持久化 | QMainWindow.saveGeometry/restoreGeometry | 替代手动的 geometry 字符串保存/解析 |
| 搜索防抖 | QTimer.singleShot(300ms) | 保持与 v1.2 相同的防抖行为 |
| 右键菜单 | QMenu + CustomContextMenu | Qt 原生菜单，支持子菜单/图标/快捷键 |
| 定时器 | QTimer | 替代 root.after()，API 更清晰 |
| 富文本编辑 | QTextEdit | 用于日记正文，支持撤销/重做/剪贴板 |
| 自动保存 | QTextEdit.textChanged → QTimer 防抖 → 保存 | 与 v1.2 lose-focus 自动保存对应 |
